# Land cover dataset

### [Google Dynamic World V1](https://developers.google.com/earth-engine/datasets/catalog/GOOGLE_DYNAMICWORLD_V1)
```
ee.ImageCollection("GOOGLE/DYNAMICWORLD/V1")
```
Dynamic World predictions are available for the Sentinel-2 L1C collection from 2015-06-27 to present.
Dynamic World is a 10m near-real-time (NRT) Land Use/Land Cover (LULC) dataset that includes class probabilities and label information for nine classes.
The nine classes are:
1. 'Water'
2. 'Trees'
3. 'Grass'
4. 'Flooded vegetation',
5. 'Crops'
6. 'Shrub and scrub'
7. 'Built'
8. 'Bare'
9. 'Snow and ice'
}

### [ESA WorldCover V100](https://developers.google.com/earth-engine/datasets/catalog/ESA_WorldCover_v100)
```
ee.ImageCollection("ESA/WORLDCOVER/V100")
``` 
This dataset provides global land cover map from 2020 at 10-meter resolution based on sentinel-1 and sentinel-2 imagery. The WorldCover product comes with 11 land cover classes: 
1. Trees
2. Shrubland 
3. Grassland
4. Cropland
5. Built-up
6. Bare/ sparse vegetation
7. Snow and ice
8. Permanent water bodies
9. Herbaceous wetlands
10. Mangroves
11. Moss and lichen.
